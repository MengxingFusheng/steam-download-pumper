# 每日调度、Ookla 直连源和独立发布器 · 2026-10-20

Fleet 统一采用每日预测调度；有下载进度的低速线路继续运行，由引擎换源和探测恢复。连续无进度、SNMP、WAN 预算、时段及目标保护保留。

发布器统一通过 Ookla 网页接口和已有测速服务器地址发现候选。使用带 `size=67108864`、`guid` 和 `nocache` 的下载模板；逐端点验证真实字节，不将 HTTP 200 或空响应视为可用。节点仅从签名清单选源，不自行发现。

每条线路最多 12 个连接。下载引擎支持绑定出口的 HTTP/2/HTTP/1.1，并连续请求现代 Ookla 分块，不再在每个成功分块后等待随机重启间隔。签名清单 schema=1 保持兼容，配置上限可达 100 条。

生产发布器应独立部署在与目标网络相符的主机，例如 `192.168.1.70`，使用 host 网络及实际 DNS/出口完成筛选，禁用经旁路由得到的旧发布结果。仅迁移签名身份及 revision，不复用旧出口的发现缓存或测速分数；同一时刻仅运行一个发布者。

本次在目标出口重新验证 114 个候选，发布 5 个实际可用直连 URL，5 个节点均确认应用，源更新保留下载进程。持续 612.7 秒实测接收约 150.8 GB，平均 1969.3 Mbps，动态分配预算平均 1962.5 Mbps，单线最大连接数为 12。结束阶段一条线路达成目标，正常转为待机。

验证包含发布器、Fleet、源清单解析，以及 Go 引擎、race 和 vet 检查。配置及运行方式见 [发布器文档](publisher-docker.md)。认证资料、运行数据库、真实账号清单和实验中的出站统计功能不包含在此版本。
