# 管理员与只读账户

统一门户及 Fleet API 支持管理员与可选只读账户。管理员名称由 `DASHBOARD_ADMIN_USER` 指定，密码继续使用原有 `DASHBOARD_ADMIN_PASSWORD_HASH_FILE`。

启用只读账户需同时配置 `DASHBOARD_VIEWER_USER` 与 `DASHBOARD_VIEWER_PASSWORD_HASH_FILE`，后者挂载独立的 scrypt 密码哈希文件。两个账户名称必须不同；只读配置出现时，门户必须已有完整的管理员认证配置。不要把明文密码或哈希提交到 Git。

只读账户可以读取节点、曲线、历史日总量、收益与 UDP 阻断状态；服务端统一拒绝其 POST、PATCH、PUT、DELETE 等变更请求，即使 CSRF 信息有效。会话登录与退出单独校验，允许只读用户安全退出。Fleet Basic API 同样允许读取并拒绝管理操作。节点注册凭据和管理令牌保持原权限。

页面显示“只读”身份，隐藏修改、启停、改名、推送等入口，保留查询、筛选、数据导出和退出。前端隐藏仅用于操作体验，授权以服务端为准。

生产账户修改通过仅含账户环境变量、哈希文件挂载和镜像的 Compose 覆盖文件部署；保留原管理员密码及数据卷，重新创建认证服务后原网页会话需重新登录。节点下载服务不需要重启。

验证：门户账户/代理测试、Fleet Basic 读写权限测试，以及浏览器下只读入口、管理员入口、动态节点详情和直接写接口拦截。
